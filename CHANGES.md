# Emu3.5 Layer-Skip Changes

This document describes all code changes made to implement the **intermediate-layer image decoding** feature — where visual tokens are generated by the full model as normal, but the images are decoded from a shallower transformer layer's hidden states rather than the final layer output.

---

## Overview

The standard Emu3.5 pipeline generates interleaved text and image tokens autoregressively, then decodes visual tokens through the VQ tokenizer to produce images. This change adds an optional `image_logits_layer` parameter. When set, a forward hook captures hidden states from the specified transformer block at each image-mode step. After each image's token sequence is complete, those captured states are projected through the final layer norm and `lm_head` to produce alternative visual token predictions, which replace the originals before VQ decoding.

**Generation is completely unchanged.** The hook is read-only — it captures states but does not modify the forward pass. The model still samples from the final layer's logits as usual.

---

## Files Changed

### `src/emu3p5/modeling_emu3.py`

The main model file. All new logic lives inside `Emu3ForCausalLM`.

#### New instance variables (`__init__`)

```python
self._image_mode_cache: weakref.WeakKeyDictionary = weakref.WeakKeyDictionary()
self._image_layer_hook: Optional[Any] = None
self._intermediate_hs: Optional[torch.Tensor] = None
self._image_layer_hs_buf: List[torch.Tensor] = []
self._suppress_hs_buffer: bool = False
```

- `_image_mode_cache`: caches whether each batch element is currently inside a `BOI…EOI` segment, keyed by the KV-cache object so it auto-invalidates when the cache is GC'd.
- `_image_layer_hook`: the registered `register_forward_hook` handle. Kept for cleanup.
- `_intermediate_hs`: receives the raw hidden states from the hooked layer each forward pass.
- `_image_layer_hs_buf`: accumulates one hidden state vector per image-mode token step (conditional passes only).
- `_suppress_hs_buffer`: flag set `True` during unconditional CFG forward passes to prevent double-buffering (see bug fix below).

#### Hook registration (`_register_image_layer_hook`)

Attaches a forward hook to `model.layers[layer_idx]`. The hook captures `output[0]` (raw hidden states before any norm). Validates the index is in `[0, num_layers - 1]`; raises `ValueError` otherwise.

Called automatically from `__init__` if `config.image_logits_layer` is set.

#### Image-mode tracking (`_in_image_mode`, `_in_image_mode_with_cache`, `_update_image_mode_state`)

Three helpers that track, per batch element, whether the current token position is inside a `BOI…EOI` image segment:

- `_in_image_mode`: scans the full `input_ids` sequence for the last `BOI`/`EOI` token.
- `_in_image_mode_with_cache`: caching wrapper — on the first call or after a prefill, runs the full scan; on subsequent single-token steps, updates incrementally via `_update_image_mode_state`.
- `_update_image_mode_state`: incremental update — checks only the newly appended token.

#### Buffer append in `forward()`

After each `self.model(...)` call, if a hook is registered and `_intermediate_hs` was populated:

```python
if (not self._suppress_hs_buffer and
        self._image_layer_hook is not None and self._intermediate_hs is not None and input_ids is not None):
    in_image = self._in_image_mode_with_cache(input_ids, past_key_values, use_cache)
    if in_image.any():
        for b in range(input_ids.shape[0]):
            if in_image[b]:
                self._image_layer_hs_buf.append(self._intermediate_hs[b, -1, :].detach().clone())
    self._intermediate_hs = None
```

The `_suppress_hs_buffer` guard is the fix for the double-buffer bug described below.

#### `reset_image_layer_buffer()`

Clears `_image_layer_hs_buf`. Must be called before each `model.generate()` call.

#### `get_image_layer_sequence(result_tokens, tokenizer)`

Used in **non-streaming** mode. After `model.generate()` completes, iterates over the generated token array, finds every `BOI…EOI` segment, and replaces visual token IDs with predictions from the buffered hidden states (passed through `model.norm + lm_head → argmax`).

Structural tokens (`EOL`, `EOF`, `TMS`, etc.) are left untouched to preserve row structure. A regex guard (`<|visual token \d+|>`) ensures only valid visual tokens are substituted — if the intermediate layer predicts a non-visual token, the original is kept as fallback.

Handles `bytes`-type returns from `tokenizer.convert_ids_to_tokens` (byte-level BPE tokens) by treating them as non-visual and keeping the original.

#### `remap_image_str(image_str, tokenizer, buf_offset)`

Used in **streaming** mode. Called by `streaming_generate` immediately after each complete `BOI…EOI` image string is assembled. Performs the same norm + lm_head projection and token substitution as `get_image_layer_sequence`, but operates on the text-form token string for a single image.

Returns `(remapped_str, new_buf_offset)`. The offset advances by `M + 1` per image (`M` inner tokens, `+1` for the EOI-prediction buffer entry).

Includes diagnostic logging:
```
[remap_image_str] buf_offset=0, M=3136, buf_total=3137, orig_rows(56)={56}
```

### `src/utils/logits_processor.py` — Double-buffer bug fix

**Problem**: The CFG logits processor calls `model.forward()` twice per generation step — once for the conditional pass (driven by `model.generate()`) and once for the unconditional pass (inside `get_unconditional_logits`). Both triggered the buffer-append code, resulting in 2×(M+1) entries per image instead of M+1. This caused all images after the first to use completely wrong hidden states.

**Fix**: Both `self.model(...)` calls in `get_unconditional_logits` are now wrapped with:

```python
if hasattr(self.model, "_suppress_hs_buffer"):
    self.model._suppress_hs_buffer = True
try:
    out = self.model(...)
finally:
    if hasattr(self.model, "_suppress_hs_buffer"):
        self.model._suppress_hs_buffer = False
```

This covers both the primary unconditional pass and the secondary `full_unconditional` pass (used for `no_text_img_cfg` mode).

### `src/utils/generation_utils.py`

#### Buffer reset before generation

Both `streaming_generate` and `non_streaming_generate` now call `model.reset_image_layer_buffer()` before starting, so stale entries from a previous call don't pollute the next run.

#### Streaming remap

In `streaming_generate`, after each complete image token string is assembled:

```python
if hasattr(model, "remap_image_str") and model._image_layer_hs_buf:
    image_token_str, _img_buf_offset = model.remap_image_str(
        image_token_str, tokenizer, _img_buf_offset
    )
```

A module-level `_img_buf_offset` counter tracks consumption across all images in a single generation call.

#### Non-streaming remap

In `non_streaming_generate`, after `model.generate()`:

```python
if hasattr(model, "get_image_layer_sequence") and model._image_layer_hs_buf:
    result = model.get_image_layer_sequence(result, tokenizer)
```

#### Verbose `decode_image` logging

`decode_image` now prints at every stage:

```
[decode_image] grid: 56 rows, widths={56}, total tokens in string=3249
[decode_image] running VQ decode on 56x56 grid...
[decode_image] OK: 896x896px
```

On failure:
```
[decode_image] FAILED: no visual token rows found — intermediate layer may have predicted non-visual tokens
[decode_image] FAILED: expected sequence of length 56 at dim 1 (got 55)
```

Previously there was only a bare `print(f"decode image failed {ex}")` with no success confirmation and no early-exit before attempting `torch.tensor` on an empty list.

### `inference.py`

#### Streaming always enabled

Inference now forces `cfg.streaming = True` for every prompt (restoring the original value afterward). This enables per-image decode and preview saving without waiting for the full sequence to complete.

#### Per-image preview saving

Each successfully decoded image is saved immediately:

```
{save_path}/preview/{name}_{img_idx:02d}.png
```

With log output:
```
[INFO] Image #1: received 3249 tokens, decoding...
[INFO] Image #1 saved → preview/000_01.png  (896x896px)
```

#### Empty ImageMeta placeholder cleanup

When `decode_image` returns `None` after an `image_cot` block created an `ImageMeta` placeholder in the proto, the placeholder is discarded:

```python
elif proto_writer.story.clips:
    proto_writer._get_last_image()
```

Without this, failed image decodes left 0-byte `image_data` entries in the proto.

#### `device_map="auto"` device fix

`model.device` returns `"meta"` when `device_map="auto"` distributes layers across GPUs. Fixed by finding the first real device:

```python
actual_device = next(
    (p.device for p in model.parameters() if p.device.type != "meta"),
    torch.device("cuda"),
)
```

All `input_ids`, `unconditional_ids`, and `full_unc_ids` tensors are now moved to `actual_device`.

#### Timing instrumentation

Wall-clock timings are now printed and written to `{save_path}/timing_metadata.txt`:

- Model load time
- Per-image generation time
- Total inference time (all prompts)

#### `image_logits_layer` forwarded to model loader

`build_emu3p5(...)` is now called with `image_logits_layer=getattr(cfg, "image_logits_layer", None)` so configs that set this field activate the hook automatically at load time.

### `src/utils/model_utils.py`

`build_emu3p5` accepts a new `image_logits_layer=None` parameter. When set, it is written into `model_config.image_logits_layer` before `Emu3ForCausalLM.from_pretrained(...)`, causing the hook to register during `__init__`.

---

### `src/utils/vis_proto.py`

#### `--layer` argument

`vis_proto.py` now accepts `--layer <tag>` (e.g. `--layer 63`). When provided, output filenames are suffixed:

```
001_00_image_layer63.png
001_00_image_cot_layer63.txt
```

Falls back to the `EMU_IMAGE_LAYER` environment variable if `--layer` is not passed.

#### Text wrapping

Question, summary, ASR text, and CoT fields are now word-wrapped at 90 characters via `textwrap.fill` before being written to `.txt` files.

## Bug Fixes Summary

| Bug | Root cause | Fix |
|---|---|---|
| **Double-buffer** (images 2–5 failed with jagged grid / wrong hidden states) | `model.forward()` ran for both conditional and unconditional CFG passes; both appended to `_image_layer_hs_buf` → 2×(M+1) entries per image | `_suppress_hs_buffer` flag in model; logits processor sets it before/after unconditional calls |
| **Empty images in proto** (0-byte `image_data`) | `image_cot` processing created empty `ImageMeta` placeholders that were never filled when `decode_image` returned `None` | Discard placeholder via `proto_writer._get_last_image()` on decode failure |
| **`TypeError: cannot use a string pattern on a bytes-like object`** | `tokenizer.convert_ids_to_tokens()` returns `bytes` for byte-level BPE tokens; `_VIS_RE.fullmatch(bytes)` raises `TypeError` | `if isinstance(pred_str, bytes): pred_str = ""` before regex check in both `get_image_layer_sequence` and `remap_image_str` |
| **`model.device` returns `"meta"`** | `device_map="auto"` distributes layers; `model.device` is not reliable | Scan model parameters for the first non-meta device |
